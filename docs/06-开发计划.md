## 工程规范（沿用至二期）

- 每模块：schema → core 服务 → 路由 → 测试（全绿才算完成）→ 前端接线
- 测试直接调 route handler（免起服务）；Mock Provider 保证离线确定性
- 提交前必过：`npx tsc --noEmit` + `npm test` + `npm run build`
- AI 相关改动必须更新 Prompt 评测集后再上线
