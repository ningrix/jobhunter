## 范围与背景

V3.3 由四项用户反馈驱动：①简历 AI 识别质量差 → 改为「文件保存为主、解析尽力而为」；②需要 Agent 按条件自动搜职位 → 职位雷达；③AI 模型配置保存后显示「已保存但停用中」→ bug 修复；④匹配偏好太抽象 → 具体值条件中心。

## Implemented

### A. AI 设置「停用」bug 修复
- 根因：`getAiSettingsView` 未配置分支返回 `enabled: false` → 前端复选框默认不勾 → 首次保存落库为停用
- 修复：未配置分支返回 `enabled: true`；前端 `setEnabled(data.configured ? data.enabled : true)`；测试断言锁定

### B. 求职条件中心（settings 页）
- 城市 / 薪资范围（3k 步进输入 + 3/5/8/10/15/20K 快捷档）/ 经验档位（无经验 0 / 3 个月 0.25 / 6 个月 0.5 / 1 / 2 / 3 / 5 年）/ 最高学历 / 岗位关键词
- 一次保存双写：`PATCH /users/me/profile`（expectedCity/salary/experienceYears/education → 匹配评分）+ `PUT /api/v1/policies/me`（cities/minSalary/maxExperienceYears/education/positions → 投递策略硬过滤 + 雷达搜索条件）
- 注意：`upsertPolicy` 为整体替换 rules，前端先 GET 合并再 PUT，不抹掉黑白名单等存量字段

### C. 简历文件化
- 上传重排：先落盘文件 + 建简历/版本记录（parseStatus=pending）→ 解析降级为尽力而为；文本提取失败 → `markParseFailed`（启用预留 parseError 列），文件与简历保留，不再 400 中断
- 新端点：`GET /api/v1/files/[id]`（owner 校验 + resolveUploadPath 防目录穿越 + 原文件名 Content-Disposition）；`GET /api/v1/resumes/file-infos`（列表解析状态）；`POST /api/v1/resumes/[id]/reparse`（读回原文件重提，定位 source=upload 最早版本避免覆盖用户手改）
- runner parse_resume 失败路径补 markParseFailed（此前失败永久 pending）
- parse_resume prompt 提质：日期归一 YYYY-MM、经历切分、学历枚举收敛、技能关键词化、量化亮点、噪音处理、禁编造（8 条规则）
- 空内容简历（未解析/失败）显式拒绝：`computeMatch` 与 `refreshRecommendations` 前置 `isResumeContentEmpty` 守卫，不再产出失真分数
- 老式 .doc 明确拒绝并引导另存 docx（不引入新依赖）

### D. 职位雷达
- `lib/safe-fetch.ts`：SSRF 防护——仅 http/https、字面量+DNS 解析双层校验拒绝环回/私有/保留 IP（含 IPv4-mapped/ULA/链路本地）、重定向逐跳复检 ≤3 跳、15s 超时、响应 ≤512KB；resolve 可注入便于测试
- `RADAR_SITES`（site-catalog.ts）：v1 单源猎聘 m 站校招企业列表（2026-09 实测可抓），加源 = 追加一行
- `adapters/radar.ts`：JobSource 注册（search 能力位 / importAssisted 归一 / URL 哈希稳定 sourceJobId）
- `radar-service.ts`：条件加载（policy 优先、profile 兜底）→ safeFetch → htmlToText（href 转 [url] 可见文本）→ 截断 12k 字符 → `runAI("radar_extract")` → 防编造校验（候选 URL 必须在抓取原文逐字符命中，否则丢弃）→ 城市/经验确定性过滤 → `importJobFromSource(source="radar")` 三级去重入库 → `agent_events`（radar_fetch / radar_extract / radar_import）分步审计
- prompt `radar_extract`：只抽页面真实条目、URL 禁止构造、薪资归一 K/月、剔除中介/培训、单次 ≤30 条、按用户条件自检
- API：`POST /api/v1/radar/run`（未配置自备模型 → 400 明确拒绝，mock 不产出假数据）+ `GET /api/v1/radar/runs`
- 前端：job-sources 页「职位雷达」卡（条件摘要 / 立即扫描 / 最近运行状态与计数）
- 模型目录 `shared/ai-models.ts` 更新至 2026-09 最新（glm-5.3 / glm-5.3-flash / deepseek-v4-flash / deepseek-v4-pro / kimi-k2.6 / qwen3.8-max / qwen3.7-plus / qwen3.8-flash，均经官方文档查证），设置页保持「只填 Key + 选模型，URL 自动派生」
