## 分层规则

1. `app/api/**` 只做：参数校验（Zod）→ 调用 core 服务 → 包装响应；不出现 SQL 与业务规则。
2. `server/core/**` 持有全部业务规则（所有权校验、状态机、聚合），可依赖 db/shared；不依赖 runner。
3. `server/ai/runner.ts` 是唯一编排 AI 任务持久化的地方（依赖 core 纯函数与 db）。
4. `shared/**` 零依赖，前后端同构使用。
5. 测试与源码同目录（`__tests__` / `*.test.ts`），随模块演进。
