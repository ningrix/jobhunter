## V4.1 — 可解释、可评估的 AI Ranking Engine（下一阶段，待批准后开工）

**不扩产品面**：不加新页面、不加新业务功能，只把现有「岗位匹配」的内核换真。

1. **激活语义层**：职位 JD 与简历向量化（用户已配的国产模型 embedding API，如智谱/Qwen），写入已有 `embeddings` 表（V4.0 前它 0 读 0 写）；mock provider 提供确定性向量保测试。
2. **混合排序**：`Match Score = w1·语义相似度 + w2·规则分（现 match-scorer 全保留） + w3·LLM Judge（结构化优势/风险/建议）`，权重用户可调，默认关闭语义层时可整体降级回纯规则（向后兼容，现有测试不破）。
3. **可解释**：每一条得分都有证据（语义命中段落引用 / 规则命中项 / LLM 结构化理由），前端复用 V3.4 溯源三行 UI。
4. **可评估**：建评测集（种子简历 × 种子 JD 的期望排序 gold set）+ 排序一致性指标（NDCG/Spearman）进 vitest——「匹配质量」第一次变成可回归的数字，而不是感觉。
5. **成本可控**：embedding/judge 调用全部走 ai_usage_logs（V4.0 地基），语义层开关在用户 AI 设置页。

## V4.2 — 最小 Quota 商业闭环（基于现有 Usage 地基）

1. `user_quotas` 表（match_limit / rewrite_limit / chat_limit / 每日重置）；
2. 免费额度（如每日 5 匹配 / 3 简历优化 / 10 问答）+ `*_quota_exceeded` 错误码带升级 CTA 文案（FRESUME 验证过的「错误码即营销位」）；
3. Pro 三档（定价锚点 ¥1 体验 / ¥9.9 周 / ¥19.9 月）+ **人工开通**后台（收款码 + 订单审核，零支付集成）；
4. 配额中间件挂在 AI 网关层（runAI 已是唯一入口，V4.0 已埋好计量）；
5. 开源定位（open-core / 双仓库 / 配额即卖点）待用户拍板后执行。
