### M2 AI Usage 成本核算（定价能力）

- `server/ai/pricing.ts`：**最长前缀命中价格表**（mock/glm-4-flash 免费，deepseek/moonshot/qwen/glm 档位，全部标 NEEDS_VERIFICATION），未知模型兜底价宁高勿低；`AI_PRICING_OVERRIDES` 环境变量可覆盖任意前缀与 `*`，坏 JSON 静默回落不炸调用链。
- gateway `logUsage` 的 `cost: 0` 占位 → `computeCost(model, in, out)` 真实折算（成功与失败调用都落）。
- `GET /api/v1/ai-usage`：本人 `{today, total, byScene}` 三口径汇总（次数/token/成本）。**从此一次简历优化多少钱可回答，定价有依据。**

### M1 Storage 抽象（部署能力）

- `server/storage/index.ts`：`StorageService{put,get,delete}` + `LocalStorage`（键格式 `data/uploads/<uuid><ext>` 与历史 files.path **零迁移兼容**，承接原目录穿越硬ening）+ `OssStorage` 占位（调用即明确报错）+ `getStorage()` 工厂（`STORAGE_DRIVER` 环境变量）。

## 为什么不是 Redis + BullMQ

本机无 Docker 无 Redis（环境既定事实）。方案取其架构、舍其基础设施：**入队→执行→事件流的三段结构与 BullMQ 同构**，`TaskEventBus` 与 `runTaskAsync` 是仅有的两个替换点；单进程内 EventEmitter 零依赖且测试全绿。云部署阶段切 Redis 驱动时业务代码零改动。
