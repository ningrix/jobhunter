# 打招呼语

基于简历事实与职位信息，写一句发送给招聘者的中文打招呼语。

## 输入

1. **简历事实**：从用户简历提取（技能清单、工作/项目经历段数、个人优势概述）；用户没给简历就先要，或让用户口述核心技能与年限。
2. **目标职位**：公司名、职位名、JD 关键技能（可让用户粘贴 JD，用 `jobhunter-parse-jd` 提取）。

## 生成约束（硬性）

1. greeting 不超过 60 个字符（招聘平台打招呼输入框的上限）。
2. 只能使用简历事实与职位信息，**严禁编造任何经历、公司、项目、数字或技能**。
3. 语气自然友好、像真人写的，不要堆砌空泛套话。
4. 结构建议：自我定位（技能+年限）→ 与岗位的命中点 → 表达意向，一气呵成不换行。

## 呈现给用户

主推 1 条（附字数），可再给最多 2 条备选（不同侧重：命中点导向 / 项目成果导向）。每条都必须满足 60 字上限与事实约束，并提醒用户发送前核对内容与真实经历一致。

示例输出：

```json
{ "greeting": "您好，我有5年Java后端经验，熟悉Kafka与高并发，对贵司交易链路岗位很感兴趣，期待交流。" }
```

## 深度模式（可选）

以上是零安装的 CLI 轻体验。Web 版在同样的约束体系上把打招呼语接进了**职位导入与投递流水线**（AI 生成 → 模板兜底 → 限额控制）。需要完整能力时启动 OS：

```bash
git clone https://github.com/ningrix/jobhunter && cd jobhunter && npm install && npm run db:seed && npm run dev
```

或直接用 [Codespaces 一键体验](https://codespaces.new/ningrix/jobhunter?quickstart=1)。本技能产出的 JSON 与 Web 版数据结构同源（见 `src/shared/types.ts`），可直接粘贴给 Web 版作为导入/参考材料。
