# 职位雷达（CLI 版）

JobHunter Web 版职位雷达的轻量移植：抓公开列表页 → AI 结构化抽取（防编造）→ 确定性条件过滤 → 职位清单。与 Web 版的差异：不入库、不做全局三级去重（改为会话内去重 + 本地存档）；不需要 API Key——**当前 CLI 的模型就是抽取引擎**。

## 第 0 步：合规边界（每次先自检）

1. 只抓取**公开可见**的招聘列表页（无需登录即可访问的页面）。
2. 只做**信息聚合**：不登录、不代填表单、不代投递、不绕过任何访问控制或反爬机制。
3. 单次任务克制：默认只抓用户给定的 1 个列表页（至多 2 个），不批量翻页爬站。
4. 抓取失败（超时/403/验证码）就如实报告并建议换来源，**绝不重试硬闯**。
5. 清单仅供用户参考，投递决策与操作永远由用户自己完成。

## 第 1 步：收集条件与来源

**条件**（可全空）：城市 / 岗位关键词 / 薪资下限（K/月）/ 最高经验年限。

**来源**（二选一）：
- 用户直接粘贴招聘列表页 URL；
- 用户只说「帮我扫」时，从内置来源清单选一个，**先展示给用户确认再抓**：

| 站点 | 列表页 | 说明 |
|---|---|---|
| 猎聘 · 校园招聘企业列表 | `https://m.liepin.com/campus/comp-list/` | 与 Web 版 RADAR_SITES 同源（站点改版以实际页面为准，NEEDS_VERIFICATION） |

用户也可以直接把页面文本粘贴进来——粘贴文本同样走第 3 步抽取，无需抓取。

## 第 2 步：抓取页面

用你（CLI）自带的网页抓取能力读取页面全文。失败时如实说明原因（超时 / 站点拒绝 / 需要登录），并建议：换一个来源，或请用户在浏览器打开页面后全选复制文本粘贴进来。

## 第 3 步：防编造结构化抽取

你是招聘信息抽取引擎。从给定网页文本中抽取真实的校园招聘/社招职位条目，输出 JSON：

```jsonc
{
  "jobs": [{
    "companyName": "公司名（页面真实出现）",
    "title": "职位名（如：2027届校园招聘-运营岗）",
    "city": "工作城市，页面未标注则为空字符串",
    "salaryMin": "数字 K/月，页面没写就 null，不要猜",
    "salaryMax": "数字 K/月",
    "jobType": "校招 或 社招",
    "employmentType": "全职 或 实习",
    "url": "该条目在页面原文中的链接路径，没有则为空字符串",
    "postedNote": "页面标注的发布日期/截止日期等，没有则为空字符串"
  }]
}
```

抽取规则（每条都是硬约束）：

1. 只能抽取页面文本中真实出现的信息，禁止编造公司名、职位名或任何字段。
2. url 必须逐字符来自页面原文中存在的链接，禁止构造、拼接、补全不存在的 URL；找不到就留空字符串。
3. salaryMin/salaryMax 为数字，单位 K/月（如 15-25K → 15 和 25；万元月薪 ×10 换算成 K）；页面没写薪资就填 null，不要猜。
4. 剔除：培训/中介/收费岗、与招聘无关的公告、广告位、互相重复的条目。
5. 用户过滤条件在真实存在的前提下于第 4 步确定性执行，本步不做条件猜测。
6. 最多输出 30 条，按信息完整度从高到低排序；页面没有可用条目就输出 `{"jobs": []}`。

## 第 4 步：条件过滤（确定性，逐条标注）

- 城市不在条件城市内 → 剔除；页面未标注城市 → 保留并标注「城市未知」。
- 经验要求高于条件上限 → 剔除。
- 薪资上限低于条件下限 → 剔除；页面未标薪资 → 保留并标注「薪资面议」。
- 汇报：抽取 N 条，过滤 M 条（原因分布），最终 K 条。

## 第 5 步：去重与呈现

1. **会话内去重**：同 URL 或同「公司+职位」合并；若用户给出历史清单文件（上次输出），读取后一并去重并标注「与上次重复」。
2. 表格呈现：公司 / 职位 / 城市 / 薪资 / 类型 / 链接（相对链接补全域名后展示）。
3. **存档**：把最终清单写入 `radar-{YYYYMMDD}-{来源}.md`（含抽取/过滤统计），供下次去重与 Web 版导入参考。

示例输出（抽取步的 JSON）：

```json
{
  "jobs": [
    { "companyName": "保融科技", "title": "2027届运营管培生", "city": "上海", "salaryMin": 15, "salaryMax": 25, "jobType": "校招", "employmentType": "全职", "url": "/campus/job/abc123", "postedNote": "2026-09-04发布" },
    { "companyName": "北京星河科技", "title": "2027校招工程师", "city": "北京", "salaryMin": null, "salaryMax": null, "jobType": "校招", "employmentType": "全职", "url": "", "postedNote": "" }
  ]
}
```

## 深度模式（可选）

以上是零安装的 CLI 轻体验。Web 版职位雷达在此基础上增加**三级指纹去重入库（EXACT/POSSIBLE/NEW）、agent_events 全链路审计、与求职条件中心/投递流水线联动**。需要完整能力时启动 OS：

```bash
git clone https://github.com/ningrix/jobhunter && cd jobhunter && npm install && npm run db:seed && npm run dev
```

或直接用 [Codespaces 一键体验](https://codespaces.new/ningrix/jobhunter?quickstart=1)。本技能产出的 JSON 与 Web 版数据结构同源（见 `src/shared/types.ts`），可直接粘贴给 Web 版作为导入/参考材料。
