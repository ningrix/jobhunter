JobHunter

欢迎使用 JobHunter

这是一个在本机运行的智能求职工具：简历工作台、职位中心、智能匹配都在你自己的电脑上完成，数据不出本机。

三步就能用起来
  • 导入或新建一份简历
  • 粘贴 JD，或让雷达扫描公开职位
  • 算匹配分，按建议改简历

数据存在哪里

数据库和上传的简历文件都放在下面这个目录，不写进程序安装目录；卸载程序也不会删除它。

准备就绪

首次启动会自动建库，大约需要几秒钟。默认使用内置的本地引擎（无需联网、无需 API Key），所有功能都能走通。

想用真实大模型？

进入应用后打开「设置 → 自备模型」，粘贴智谱 / DeepSeek / Kimi / 通义 的 API Key 即可，Key 会加密保存在本机。
